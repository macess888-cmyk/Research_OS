# Research OS

A Streamlit-based academic portfolio and research dossier system for managing biography, publications, software, teaching, collaborations, timelines, and research outputs from Markdown source files.

## Current Instance

Jake Macdonald Academic Portfolio

## Features

- Modular Streamlit app
- Markdown content source
- Sidebar navigation
- Research dashboard
- Research Atlas
- Admin Editor
- Build Center
- Backup export
- Live project statistics

## Cross-Module Research Integration

Research_OS also provides a neutral documentation index for bounded cross-repository inspection work. These documents connect evidence surfaces without merging module authority:

- [MODULE DELTA MATRIX 001](docs/MODULE_DELTA_MATRIX_001.md)
- [CROSS-MODULE TRANSITION CONNECTIONS 001](docs/CROSS_MODULE_TRANSITION_CONNECTIONS_001.md)

```text
shared evidence objects

shared authority
```
